## Publicação

O site é publicado na **Vercel**, ligada a este repositório: cada push no `main` atualiza o site. A Vercel também roda a função `api/dificuldade.js`, que envia o formulário direto para o WhatsApp pela API oficial da Meta.

O GitHub Pages não serve mais, porque não roda a função do formulário.

Para configurar o envio para o WhatsApp, siga [docs/CONFIGURAR-WHATSAPP.md](docs/CONFIGURAR-WHATSAPP.md).
